# Class notes archive

`https://www.math.utah.edu/~css/` and are now served by GitHub Pages at `https://xian22.github.io/class-notes/`.
Folder names match the old server paths, so old links map one-to-one.

The course pages that link here are in [xian22.github.io](https://github.com/xian22/xian22.github.io).
